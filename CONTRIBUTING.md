# Contributing

Thanks for helping make the starter more useful without making it more invasive.

## Good contributions

- new adapter examples using synthetic fixtures
- provider-agnostic normalization utilities
- accessibility and responsive improvements
- tests for idempotency, validation, and ranking properties
- clearer diagrams and setup guides
- safer defaults for the local bridge

## Keep out of pull requests

- real watchlists or private creator research
- tuned personal scoring logic
- production prompts or evaluation corpora
- credentials, session data, tokens, cookies, or private endpoints
- scraped fixtures without a clear right to redistribute

## Development

```bash
npm install
npm run dev:web
npm run check
```

Keep changes focused. Explain the adapter boundary, add tests, and update documentation when behavior changes.
