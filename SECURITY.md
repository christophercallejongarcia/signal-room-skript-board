# Security Policy

Please report vulnerabilities privately through GitHub Security Advisories for this repository. Do not include credentials, tokens, private creator data, or exploit details in a public issue.

See [docs/SECURITY.md](docs/SECURITY.md) for the trust model. This repository is private and is not published, so the public-release checklist there does not apply; see [ADR-0006](docs/adr/0006-repo-ist-privates-produkt.md).
